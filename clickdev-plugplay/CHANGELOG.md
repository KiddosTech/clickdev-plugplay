# Changelog

All notable changes to Clickdev PlugPlay will be documented here.

## [1.0.0] — 2025

### Added
- Visual event editor panel inside Godot editor
- 8 condition categories: General, Input, Object, Collision, Variable, Timer, Scene, Math
- 9 action categories: Movement, Object, Animation, Sound, Variable, Timer, Scene, System, Debug
- 30+ built-in conditions
- 65+ built-in actions
- NOT checkbox to negate any condition
- Auto GDScript code generation from visual events
- Code preview panel
- ClickdevEventSheet node — holds events, select to open editor
- ClickdevObject node — CharacterBody2D with gravity & alterable values
- ClickdevTimer node — named timer for use in events
- Events saved persistently inside .tscn scene file
